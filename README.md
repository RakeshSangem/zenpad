# Zenpad

A distraction-free, local-first notes app. Writing works without an account or
network connection; signing in only enables backup and cross-device sync.

## Local data

Notes are stored with the browser's native IndexedDB API in the `zenpad`
database. No IndexedDB wrapper library is used. The database contains stores
for notes, settings, sync metadata, and the future durable sync queue.

Existing notes from the old `zenpad-storage` localStorage entry are migrated to
IndexedDB once and the old entry is removed. Authentication tokens remain in
localStorage for the current web implementation.

## Editing

Plain-text mode is the default. Enable Markdown from the sidebar to use the
Tiptap editor. Type `/` to open the contextual block menu for headings, lists,
checklists, code blocks, quotes, and dividers. There is no permanent formatting
toolbar.

## UI foundation

The interface uses shadcn/ui components generated by the official CLI with
Base UI primitives. Tailwind CSS v4 is integrated through the Vite plugin.
Zenpad keeps its existing neutral styling, system font, system dark-mode
preference, and custom auth/sidebar motion on top of those primitives.

Add future components through the registry rather than copying them manually:

```bash
npx shadcn@latest add <component>
```

Each rich note stores both:

- Tiptap JSON as the structured, forward-compatible document
- Markdown as a portable projection for export, search, previews, and clients
  that do not use Tiptap

The official Tiptap Markdown extension is currently beta, so the JSON document
is retained rather than relying on Markdown to preserve every future node type.

## Optional sync

Anonymous users make no API calls. After login/signup, the local workspace is
attached to that account, remote notes are pulled, and local notes and deletion
tombstones are pushed to the Zenpad API. A local workspace will not silently
sync into a different account.

## Run locally

Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev
```

The app is available at `http://localhost:3000`. The API defaults to
`http://localhost:8787`; override it with `VITE_API_URL`.

```bash
npm run build
npm run preview
```

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `Cmd/Ctrl + N` | Create a note |
| `Cmd/Ctrl + S` | Name/save a note |
| `Cmd/Ctrl + D` | Delete the current note |
| `Cmd/Ctrl + B` | Toggle sidebar outside the rich editor; bold inside it |
| `Cmd/Ctrl + ↑/↓` | Navigate notes |
| `?` | Show shortcut help |
| `/` | Open the rich block menu in Markdown mode |

When the `/` menu is open, `Arrow Up/Down` and `Tab/Shift+Tab` cycle through
commands, `Home/End` jump to the first or last command, `Enter` applies the
selected command, and `Escape` dismisses the menu while returning control to
the editor. Run `npm test` to verify this keyboard contract.
